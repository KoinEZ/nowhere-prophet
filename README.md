# Русификатор Nowhere Prophet

Следующий перевод - карточная игра [Nowhere Prophet](https://store.steampowered.com/app/681730/Nowhere_Prophet/), подаренная мне кем-то, пожелавшим остаться инкогнито[https://store.steampowered.com/app/681730/Nowhere_Prophet/](https://store.steampowered.com/app/681730/Nowhere_Prophet/)

[`NowhereProphet-RU-v1.1.zip`](NowhereProphet-RU-v1.1.zip)
Что сделано:

- Весь текст игры = 1505 строк: диалоги и события, интерфейс, меню, карточки, подсказки
- Всё адаптировано под русский, никаких наездов текста/кривых текстур быть не должно
- Кириллица в шрифтах на месте, ручной ввод русского не крашит игру, сохранения совместимы

Установка:

- Найдите папку игры: Steam -> ПКМ по Nowhere Prophet -> Свойства -> Установленные файлы -> Обзор... (откроется папка игры, нужна подпапка NowhereProphet_Data
- Положите в неё (NowhereProphet_Data) файл из архива (resources.assets), заменив существующий
- Запустите игру. Меняем язык в: OPTIONS -> GAME -> LANGUAGE -> Русский.
